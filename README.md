## About

This blog is where I document things I learn, problems I solve, and tools I find useful. Topics range from Linux server administration and DevOps to web development and open-source software.

Written in Turkish, for the Turkish developer community.

## Stack

- **[Jekyll](https://jekyllrb.com)** — static site generator
- **[Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy)** — theme
- **[GitHub Pages](https://pages.github.com)** — hosting
- **[GitHub Actions](https://github.com/features/actions)** — automated build & deploy

## Local Development

```bash
git clone https://github.com/bekircem/bekircem.github.io.git
cd bekircem.github.io
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000` in your browser.

## Writing a Post

Create a new file under `_posts/` following the naming convention:

```
_posts/YYYY-MM-DD-post-title.md
```

With this front matter:

```yaml
---
title: "Post Title"
date: YYYY-MM-DD HH:MM:SS +0300
categories: [Category]
tags: [tag1, tag2]
---
```
